# คู่มือเปิดโปรเจกต์ KMITL Marketplace ใน VS Code (ภาษาไทย)

## ต้องติดตั้งก่อน

- **Docker Desktop** — เอาไว้เปิด PostgreSQL, Backend, Frontend พร้อมกัน
- **VS Code** — เปิดแก้ไขโค้ดในโปรเจกต์
- **Git** — สำหรับทำงานร่วมกันบน GitHub
- ต้องใช้อินเทอร์เน็ตในการดาวน์โหลด Docker images และไลบรารีครั้งแรก

## วิธีเปิดง่ายที่สุด

1. แตกไฟล์ `KMITL_Marketplace.zip`
2. ใน VS Code กด `File > Open Folder` แล้วเลือกโฟลเดอร์ `KMITL_Marketplace`
3. เปิด `Terminal > New Terminal` (ต้องอยู่ในโฟลเดอร์ที่มีไฟล์ `docker-compose.yml`)
4. พิมพ์คำสั่ง:

```powershell
docker compose up --build
```

5. เปิด Browser:
   - เว็บหลัก: **http://localhost:3000**
   - เอกสาร API อัตโนมัติ: **http://localhost:8000/docs**
   - ตรวจ Backend และฐานข้อมูล: **http://localhost:8000/health**

**ห้ามเปิดไฟล์ `page.tsx` ตรง ๆ ด้วยเบราว์เซอร์** เพราะต้องรัน Next.js Server ก่อน

## วิธีทดลองระบบ

1. หน้าเว็บ → เข้าสู่ระบบ → พิมพ์ `student01@kmitl.ac.th` (อีเมลตัวอย่างเพื่อทดสอบ)
2. กดส่ง OTP → ในโหมดทดสอบจะเห็นรหัสใต้ช่องกรอก ให้นำไปใส่ (ยังไม่ส่งอีเมลจริง)
3. ไปที่ `ลงขาย` ใส่สินค้า เช่น `หนังสือ Python` ราคา `250` บาท แนบรูป แล้วเผยแพร่
4. เปิด Chrome Incognito → เข้าเว็บเดิม → ล็อกอินด้วยอีเมล **คนละชื่อ** เช่น `student02@kmitl.ac.th`
5. ค้นหาสินค้า → กดจอง → ส่งข้อความถึงผู้ขาย
6. กลับหน้าต่างผู้ขาย → เปิดการแจ้งเตือน/ข้อความ → กดยืนยันขายเสร็จ
7. หน้าต่างผู้ซื้อ → รีวิว 1–5 ดาว
8. ผู้ซื้อกดรายงานสินค้า → ลองเข้าบัญชีผู้ดูแล **ในโหมด Local Demo เท่านั้น** `admin@kmitl.ac.th` → เมนู `ผู้ดูแล`

> ระบบ OTP แบบโชว์รหัสนี้ **ใช้ทดสอบในเครื่องเท่านั้น** ไม่ได้พิสูจน์ว่าเป็นเจ้าของอีเมลจริง ห้ามนำการตั้งค่านี้ไปใช้บริการสาธารณะ ต้องตั้งค่า SMTP และเปลี่ยนเป็น `ENV=production` ก่อน

## รันด้วย Python + npm โดยไม่ใช้ Docker

เลือกวิธีนี้เมื่อไม่มี Docker แต่มี Python / Node.js / npm ติดตั้งแล้ว

**Terminal 1:**

```powershell
cd backend
py -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
```

เปิดไฟล์ `backend/.env` แก้บรรทัด `DATABASE_URL=...` เป็น `DATABASE_URL=sqlite:///./marketplace.db` เพื่อทดสอบในเครื่อง แล้วรัน:

```powershell
python -m uvicorn app.main:app --reload --port 8000
```

**Terminal 2:**

```powershell
cd frontend
Copy-Item .env.example .env.local
npm install
npm run dev
```

หากจะใช้ PostgreSQL ตามสเปกจริง แนะนำ Docker Compose หรือรัน PostgreSQL Server แล้วใช้ connection string ที่ถูกต้องแทน SQLite

## คำสั่งตรวจสอบสำหรับส่งอาจารย์

**ใน `backend/`:**

```powershell
python -m pytest -q tests
```

**ใน `frontend/`:**

```powershell
npm run lint
npm run typecheck
npm run build
```

GitHub Actions จะรันคำสั่งตรวจสอบอัตโนมัติเมื่อ Push หรือเปิด Pull Request หลังอัปขึ้น GitHub และมีอินเทอร์เน็ต
